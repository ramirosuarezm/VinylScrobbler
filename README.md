<h1>VinylScrobbler</h1>

<p>
  Mobile-first PWA for browsing your Discogs vinyl collection
  and scrobbling albums to Last.fm.
</p>

<h2>Features</h2>

<ul>
  <li>Discogs collection sync</li>
  <li>Track selection</li>
  <li>Last.fm scrobbling</li>
  <li>Dark mode</li>
  <li>Mobile app install support</li>
  <li>Responsive UI</li>
</ul>

<h2>Tech Stack</h2>

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>Vanilla JavaScript</li>
  <li>Discogs API</li>
  <li>Last.fm API</li>
  <li>Progressive Web App (PWA)</li>
</ul>

<h2>Installation</h2>

<ol>
  <li>Clone the repository</li>
  <li>Open <code>index.html</code></li>
  <li>Configure your Discogs and Last.fm credentials</li>
</ol>
